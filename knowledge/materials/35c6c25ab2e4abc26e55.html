让 Agent 学会接棒：MPT 的启发与被放大的结论

南晚Nanwan 在 X 上从多智能体的常见痛点讲起：中央调度器可能误解任务，成员能力更新后，固定流程却没有跟着改变。其介绍的 MPT（Market-Based Post-Training）把下一步由谁执行也纳入训练：每个 Agent 同时学习动作和出价，出价影响执行权与局部信用分配，让成员随着任务状态调整分工。这个视角有启发性，因为它把编排当作可学习能力，而不只是外部手写流程。原论文涵盖具身制作、机器人导航和深度研究任务，并与不同编排方式比较。

但原帖有几处把实验写得太满。论文使用密封竞价，并不是参与者互相看着出价的公开拍卖；测试扩展规模为 3、6、9、12 个 Agent，扩展主要通过复制已有策略。所谓“90% 节点宕机后几乎无损”，原文对应的是随机失活压力测试：在 Iron Pickaxe 任务的 32 个随机种子、每种子三次运行中，当 p=0.9 时，十二 Agent 的平均 episode reward 约 33，三 Agent 约 19。这个比较支持冗余成员在该模拟设置下保留更多回报，不能翻译成永久损失九成生产节点后任务完成率不变。

观点原文

公开推荐流原帖。以下忠实转述作者论证；其中弹性与规模外推属于原作者主张，正文已逐项限定实验范围。

忠实转述（非原句）：作者首先列举中央编排的两个痛点：调度器误解、超限或超时会影响全局；成员后训练变强后，固定调度却未必随之改变。于是他看重 MPT 同时训练动作与出价，让成员按当前任务争取执行权，并用局部信用分配将结果反馈给参与者。在他的解释里，盲目高价接手却失败应承担更大惩罚，真正擅长的成员才会受益，群体因此学会分工。

接着，他介绍具身制作、导航和深度研究三个场景，强调参与模式能随训练重构。原帖把复制扩展和失活测试解读为很强的运行弹性，还认为自组织群体能更快适应新任务。最后，他将这条路线与不断增加系统提示、状态机和超级协调器的做法比较，认为当成员走向成百上千时，学习竞价与合作值得优先探索，并推荐做多智能体编排、任务规划和鲁棒系统的人精读论文。

编辑评读

值得研究的是分工与能力一起更新，以及奖励怎样让擅长者接手合适的步骤。其成立需要可计算的外部奖励、训练时可用的反事实 rollout 和可重复环境；现实任务中的不可逆工具操作、权限与成本还要单独处理。局部信用分配也不是证明 Agent 获得了人的“自我认知”。

评论者指出原帖没有交代传统方式的好处。固定流程在职责清晰、动作可审计的任务里有实际价值；这不否定 MPT，而是要求比较相同任务质量、训练开销、推理调用量和故障模型。论文规模也不足以支持原帖对数百上千成员的推断。本轮未找到针对该版本的独立复现实验，适合读作研究方向和争论，暂不能据此替换生产编排。

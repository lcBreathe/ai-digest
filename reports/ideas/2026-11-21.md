# 合奏中的同一个音，应该留下几份

2026-11-21 · 独立研究笔记

MIDI 用音高、时长和力度等事件记录演奏，便于在音乐软件里继续修改。把录音转成 MIDI 后，使用者往往还要调整音符和乐器轨道。一个容易被总分隐藏的选择是：两个乐器同时奏出同一音高时，输出应该保留两份音符，还是合成一个事件？这既影响评分，也影响后来能否独立编辑每个声部。

本期从全库十个技术方向的入口比较出发，读了音频读出层、完整会话服务、机器人经验蒸馏和视觉惯性建图等材料。音频方向有公开权重、可单独调用的阶段，以及新的具体解码说明，因此收敛为一项小规模复现。本期复现将分别检查检测、分组和主动合并，不主张发明新的转写算法；下文区分已有做法、拟议比较和仍缺少的证据。

## 复现同音合奏的合并取舍，再决定怎样整理轨道

值得一试的复现 · 音乐转写 / 音符分组 / MIDI / 误差分析

固定一次转写结果，观察不同合并约定如何改变音符评分与可编辑的声部；先解释一个真实取舍，再考虑改模型。

### 他们已经做了什么

Dettato 已公开四阶段流水线与权重。分轨模块读取音符、音频和转写器特征，再把音符聚类、跨窗口衔接并命名。模型卡说明了几项实际规则：很短的轨道可能并入大轨，同名乐器轨道会合并，同一轨道内相距30毫秒以内的同音音符也会合并。作者优先减少零散轨道，承认部分乐器仍会混淆；完整链路并未按分轨模块的独立基准评分。

Berendes 等人在 DAGA 2026 的研究讨论了更基础的歧义：乐谱上同时发生的同音，在实际演奏中可能略微错开；按乐谱位置合并、按音频时间帧合并，或完全不合并，会让同一转写输出得到不同的评价。他们已分析多个数据集，并在 PHENICX 上展示这种差别，所以“标注方式会影响分数”本身不是新发现。

### 为什么把这些线索放在一起

全库11月7日的音频读出层想法，关心通用表征转成文字时词表和窗口丢掉了什么；长期观察则强调通过检查只保证检查覆盖的承诺。这里保留这个问题意识，但对象改为音乐中的声部：多个正确的音高事件经过分组和合并，是否仍能支持使用者想做的编辑？

11月21日的 Dettato 学习入口已经建议检查音高、分轨和修补时间，单纯重复那项练习不值得再发一份 idea。本次补读的增量是明确的同名轨道与30毫秒合并规则，以及独立论文给出的标注约定对照。它们允许把“分轨不好”拆成检测不足、乐器归属错误和主动合并三种不同解释。

### 可以往哪些方向走

先选一个清楚的用途，例如从两种乐器的合奏中提取其中一个声部。用自己制作或许可明确的短多轨音频保留原始 MIDI，安排同音齐奏、稍微错开的同音和普通和弦三类片段。第一轮只需少量能逐音检查的样本，固定模型和音频，保存每个阶段的音符及轨道结果；不要从一开始就把目标扩成全部音乐类型的排行榜。

随后固定转写器的输出，对照按乐谱同音、按时间窗口以及不合并的参考约定，看看哪些得分变化只是目标表示改变。另检查分组前后哪些音符被移动、并入或删除。若能在公开实现中安全暴露合并前结果，再比较默认解码与保留候选轨道；本轮只读了模型卡，尚未确认这一改动的接口成本，不把它列成现成开关。

最终让一位熟悉 MIDI 的使用者尝试完成同一个小任务，例如单独修改第二声部的力度，记录需要拆开、补回和重分配哪些音符。听感、按用途的可编辑性与音符 F1 分开报告。若保留候选只增加无用碎轨，便应保留默认合并；若损失发生在最初检测，修改后处理也补不回，需要回到更早阶段。上述比较都是建议，尚未运行。

### 值得做在哪里

复现价值在于学会沿着输出形成过程解释错误，而不是把所有混淆都归因于参数太小。工程上，它可能帮助制作一个让用户查看合并原因、按用途恢复候选声部的工具；但只有实际编辑任务显示收益，才值得承担额外界面和状态管理。

研究上的可延伸问题是：哪些声学条件允许可靠地区分同音声部，哪些只能保留歧义。现有论文已说明评价约定的问题，本候选不主张方法新颖，也不预告会提高总分。即使默认解码最终最好，一份说明它在何时合并、为何有益、何时损失可编辑信息的复现记录，也能帮助采用者选对用途。

### 从哪里开始看

先读 Dettato README 的四阶段说明，再读 grouper 模型卡的 How It Works、Results 和 Limits；图中分组位于证据修复之后，但独立分组基准使用的是转写器音符，首次记录应把两种输入分清。接着读同音研究第1—3页的标注方法、三种合并策略和图6，用一个双乐器同音例子写出自己真正要保留的目标。

运行前确认权重可取得、各阶段能否导出所需结果，以及样本许可。模型卡列出部分训练素材仅限非商业研究，不能从代码和权重的 Apache-2.0 标签直接推出所有素材均可商用。本期没有下载模型、运行推理或修改项目代码；若拿不到可追溯的多轨参考，就先做合成短例子，并明确它只回答受控条件下的取舍。

### 暂时不往哪里走

这是对公开机制的复现与工程探索；不把论文的标注敏感性当成Dettato具体错误的独立证实，也不保证能从混合录音唯一恢复所有演奏者。

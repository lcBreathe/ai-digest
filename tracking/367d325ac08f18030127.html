让 Agent 学会接棒：MPT 的启发与被放大的结论

按时间保留当时的判断和后续核查；历史收录不代表刚刚重新验证。

2026-10-18 · 当时的记录

南晚Nanwan 在 X 上从多智能体的常见痛点讲起：中央调度器可能误解任务，成员能力更新后，固定流程却没有跟着改变。其介绍的 MPT（Market-Based Post-Training）把下一步由谁执行也纳入训练：每个 Agent 同时学习动作和出价，出价影响执行权与局部信用分配，让成员随着任务状态调整分工。这个视角有启发性，因为它把编排当作可学习能力，而不只是外部手写流程。原论文涵盖具身制作、机器人导航和深度研究任务，并与不同编排方式比较。

但原帖有几处把实验写得太满。论文使用密封竞价，并不是参与者互相看着出价的公开拍卖；测试扩展规模为 3、6、9、12 个 Agent，扩展主要通过复制已有策略。所谓“90% 节点宕机后几乎无损”，原文对应的是随机失活压力测试：在 Iron Pickaxe 任务的 32 个随机种子、每种子三次运行中，当 p=0.9 时，十二 Agent 的平均 episode reward 约 33，三 Agent 约 19。这个比较支持冗余成员在该模拟设置下保留更多回报，不能翻译成永久损失九成生产节点后任务完成率不变。

本次记录的观点：南晚Nanwan · jason（@disunlimited） · bear moe（@mooebear）

同事电脑上的 Agent 正在改后端接口，自己这边的 Agent 能否直接问它，而不用人复制两段聊天？Reason Network 为运行中的会话建立目录，标出所属人、电脑、仓库、分支和当前状态，通过 iroh 直连或加密中继传递消息。当前文档同时支持 Reason 工作区和免账号组队；不同客户端的收件能力并不相同，有的可在会话中推送，有的等下一步，有的需要查收 inbox。它首先解决“找到谁、怎样联系”的问题。

消息也有不同阶段：保存、送达、被暂缓或拒收，不能把送达回执解释为任务完成。设计文档说明了团队成员校验、接收策略、把同伴文字标为外部输入，以及限速和连续往返限制。这些是实现者描述的保护措施，不是安全性证明。与此同时，0xLogicrw 从这个项目谈到自己做 AGPair 的经历：为了让两个编程 Agent 协作，最后却把大量时间花在管理进程、恢复失败和检查交付上。
